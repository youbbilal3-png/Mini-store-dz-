# Mini Store DZ

A responsive Arabic/English mini-store template. Visitors can browse products, search and filter the catalog, then order through WhatsApp.

## Files
- index.html: page structure
- styles.css: responsive design
- app.js: demo products, language switch, search, filters and WhatsApp links

## Customize before publishing
1. Open app.js.
2. Replace 213000000000 in STORE_WHATSAPP with the store owner's WhatsApp number (country code, no plus sign or spaces).
3. Edit the products array with real product names, prices and descriptions.
4. Replace the sample store text with the business details.

## Publish
This is a static website. It can be deployed using Cloudflare Pages by connecting this GitHub repository. No build command is required; use the repository root as the output directory.

The products and WhatsApp number are demo content. Update them before sharing the store.
